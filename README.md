## Catatan Pribadi

Jika ingin klona di komputer lain. Taruh di direktori berikut:

```text
    .
    ├── Course
    │   ├── Programmer Zaman Now
    |   |   ├── GIT
    |   |   └── ...
    |   └── ...
    └── ...
```

Jika sudah di berada di folder **GIT**, baru clone.

```shell
git clone https://github.com/bagusperdanay7/belajar-git-remote.git
```
